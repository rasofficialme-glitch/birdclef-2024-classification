

\# BirdCLEF 2024 - Bird Species Classification



\## Overview

This project explores automated bird species classification

using bird audio recordings from the BirdCLEF 2024 dataset.



\## Objectives

\- Classify bird species from audio recordings.

\- Convert audio segments into log-Mel spectrograms.

\- Use EfficientNet-B0 for audio-based classification.

\- Explore semi-supervised learning through pseudo-labeling.

\- Investigate model efficiency through knowledge distillation,

&#x20; pruning, and quantization.



\## Methodology

Bird audio is segmented into fixed-duration clips, converted

into log-Mel spectrograms, and passed to a deep learning model

for species classification.



\## Dataset

The project uses the BirdCLEF 2024 dataset.

Download it from the official

\[Kaggle BirdCLEF 2024 competition](https://www.kaggle.com/competitions/birdclef-2024).



The dataset is not included in this repository.

Follow the dataset's license and attribution requirements.
